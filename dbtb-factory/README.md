# DBTB FACTORY — DON'T BUY THE BOOK | BRAIN FACTORY

> 책은 문제의 해결이 아니라 새로운 질문의 시작.

PRD v1.0(2026-11-19)을 바탕으로 만든 복고풍 지식가공공장 웹앱입니다.
프로젝트 설계 → 원재료 투입 → 가공설비(레버) / 특별 사고 실험실 → 프로토타입 보존 → 공장장 검수 → 최종 조립 → 완제품 창고 → 외부 AI 이관까지 한 흐름으로 동작합니다.

## 실행
```bash
cd dbtb-factory
npm install
cp .env.example .env   # ANTHROPIC_API_KEY 입력 (없으면 "데모 엔진"으로 동작)
npm start              # http://localhost:3100
npm test               # PRD 13.1 인수 테스트(API 수준, 키 불필요)
```
Node 20 이상. 배포는 `npm start` + 환경변수만 있으면 됩니다(Render/Railway/Fly 등).
데이터는 `data/db.json`에 저장되므로 재시작 시 디스크가 지워지는 호스팅에서는 지속 디스크를 붙이세요.

## AI 설계 메모
- 공식 Anthropic SDK(`@anthropic-ai/sdk`), 기본 모델 `claude-opus-5-5`, structured outputs(`output_config.format`)로 JSON을 받습니다.
- 거절(refusal) 시 서버측 대체 모델(`fallbacks: "default"`)을 켜 두었습니다. `AI_FALLBACKS=off`로 끌 수 있습니다.
- 다자간 토론은 PRD AI-04의 "경제적 버전"대로 **한 번의 호출이 여러 캐릭터 발언을 조율**합니다. 최근 40개 메시지만 전달하고, 사용자 발언 12회 상한이 있습니다.
- 원재료는 비신뢰 입력으로 `<material>` 태그에 넣고 지시를 따르지 않도록 했습니다. 원문이 없는 책은 "공개자료 기반 관점 분석"으로 표시하고, 근거·AI 해석·가설을 데이터에서도 분리합니다.

## 아직 정해지지 않은 것 (PRD 14.1)
- **로그인**: 지금은 브라우저별 익명 작업자 ID(`x-dbtb-owner`)로 프로젝트를 구분합니다. 다른 기기와 공유되지 않으며, 실제 인증으로 교체해야 합니다.
- **PDF/EPUB 본문 추출**: 파일명만 기록하고, 분석할 부분은 사용자가 붙여넣습니다(.txt/.md/.srt/.vtt는 브라우저에서 읽음). 파일은 서버에 업로드되지 않습니다.
- **도서 데이터**: Open Library 공개 API만 사용합니다. 국내 서점 페이지는 수집하지 않습니다.
- **저장소**: JSON 파일. 운영 시 PostgreSQL 등으로 교체(`lib/store.js` 인터페이스 유지).
- **진행상태 전달**: SSE 대신 1초 간격 폴링입니다.
- 과금·개인정보 처리방침·파일 보관 정책·벽돌공장 최종 이미지·법무 검토.
